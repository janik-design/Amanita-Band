## Jak zacząć / Getting started
Pobierz ZIP, rozpakuj, uruchom `.exe`. Nie trzeba instalować. Windows 10 lub 11 (64-bit). / Download the ZIP, unzip it and run the `.exe`. No installer. Windows 10 or 11 (64-bit).

Programy nie są jeszcze podpisane, więc Windows może pokazać „System Windows ochronił ten komputer”: kliknij **Więcej informacji → Uruchom mimo to**. / The programs are not code-signed yet, so Windows may show "Windows protected your PC": click **More info → Run anyway**.

## Prywatność / Privacy
Programy nie wysyłają żadnych danych i nie mają telemetrii. / The programs send no data and have no telemetry.
